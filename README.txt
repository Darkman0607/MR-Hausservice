MR HAUSSERVICE – VERSION 1.0

SCHNELLSTART AUF ANDROID / PC:
1. ZIP entpacken.
2. index.html im Browser öffnen (Chrome, Edge oder Firefox).
3. Alle Bereiche sind getrennte Seiten in derselben Web-App.
4. Zum Übertragen: Verwaltung > Sicherung als JSON speichern. Die JSON-Datei z.B. über Google Drive auf das andere Gerät übertragen. Dort die App öffnen und Verwaltung > Sicherung einlesen wählen.

WICHTIG:
- Beim Öffnen der lokalen HTML-Datei ist keine reguläre PWA-Installation garantiert. Für „Zum Startbildschirm hinzufügen“ als eigenständige installierbare PWA die Dateien auf einem HTTPS-Webhost bereitstellen.
- Speichern erfolgt lokal im Browser (localStorage), nicht in Google Drive. Cache/Sitedaten löschen oder Browser wechseln kann Daten löschen.
- Fotos werden verkleinert, belegen aber Speicherplatz. Viele Fotos können den lokalen Speicher füllen.
- Sicherung regelmäßig exportieren. Der Import ersetzt alle lokalen Daten.
- Echte Einnahmen und fiktive Übungswerte werden getrennt erfasst.
- Keine Kundenverwaltung, Cloud-Synchronisation oder Rechnungserstellung in Version 1.0.
