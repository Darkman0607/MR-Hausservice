MR-HAUSSERVICE 1.9.8.5 – GITHUB UPLOAD

Wichtig vor jedem Update:
1. In der installierten MR-App zuerst Profil > Gesamte App sichern.
2. Die JSON-Sicherung außerhalb von GitHub aufbewahren und NICHT ins öffentliche Repository hochladen. Gesundheitseinträge sind darin mitsamt Schlüssel enthalten.
3. GitHub veröffentlicht nur Programmdateien; deine bereits lokal im Handy gespeicherten Daten werden dadurch nicht automatisch hochgeladen oder synchronisiert.

Variante A – vollständige Version (empfohlen, wenn dein Repository nicht vollständig auf V1.9.8.4 ist):
- MR_Hausservice_V1_9_8_5_VOLLSTAENDIG.zip herunterladen und entpacken.
- Alle entpackten Dateien und Ordner in die WURZEL deines vorhandenen Repositories kopieren, nicht den ZIP-Container in GitHub ablegen.
- Über GitHub Desktop: Änderungen prüfen, EINEN Commit erstellen, einmal auf main pushen.
- Browser-Upload: GitHub erlaubt maximal 100 Dateien auf einmal. Deshalb ist die Vollversion mit deutlich mehr Dateien dort nicht als EIN Browser-Upload geeignet.
- Weder den Ordner frauen-app (kleines f) noch family_assets beim Übertragen weglassen.

Variante B – kleines GitHub-Update:
- NUR wenn die Dateien von V1.9.8.4 bereits vollständig im Repository liegen: MR_Hausservice_V1_9_8_5_NUR_AENDERUNGEN.zip entpacken und die enthaltenen Dateien/Ordner in dieselben Pfade hochladen. Alte passende Dateien ersetzen.
- Dieses Paket enthält nur die gegenüber V1.9.8.4 geänderten Dateien und führt daher keine neuen Familienbilder oder Frauen-App-Dateien mit.
- Einzelner Upload/Commit reicht bei korrekter Ausgangsversion.

Nach dem Push:
- Nicht wiederholt neu hochladen. In Actions / Deployments warten, bis genau die neueste Bereitstellung grün ist.
- Die installierte Seite neu laden; in der App keine Browser-/Website-Daten löschen!
- Datum/Version prüfen; Familie, Haushalt, Frauen-App und Foto-Funktionen testen.
- Falls das Deployment rot bleibt: Auf "Failed to deploy" klicken und die Fehlermeldung im Schritt "build/deploy" weitergeben. Ohne GitHub-Log ist die Ursache nicht sicher bestimmbar.

Hinweis: Auf GitHub ist das Repository PUBLIC. Niemals private Gesamtsicherungen mit Frauengesundheitsdaten, Kundenadressen oder privaten Finanzen dort hochladen.
