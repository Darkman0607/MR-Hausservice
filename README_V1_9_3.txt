MR-Hausservice V1.9.3

Änderungen:
- Backup-Paket auf grundlegende Integrität und Foto-Anzahl prüfen
- JSON-Backup-Datei im Profil gezielt prüfen, ohne vorhandene Daten zu verändern
- Größe der Datensicherung im Profil abschätzen
- Update-Check mit frischem Versionsabruf; bei Aktualisierung neue URL mit Versionsparameter
- Arbeitssitzungen tagesgenau verteilen, einschließlich Monatswechsel und Pausen
- Alte Stunden ohne Sitzungs-Zeitstempel bleiben dem bisherigen Arbeitsdatum zugeordnet
- Einheitlichere, größere Schaltflächen und Zurück zur Startseite
- Direkte Schnellzugriffe zu Zeit, Aufgaben, Material, Fotos innerhalb jeder Arbeit
- Rückmeldungen für Speichern und Backup-Import

INSTALLATION
1. UNBEDINGT VORHER bestehendes vollständiges JSON-Backup erstellen und auf Google Drive sichern.
2. ZIP entpacken.
3. index.html, sw.js, manifest.webmanifest, version.json, die beiden icon-Dateien und README im GitHub Repo-Stamm ersetzen/hochladen.
4. GitHub Actions Veröffentlichungsstatus prüfen.
5. V1.9.3 per https://darkman0607.github.io/MR-Hausservice/index.html?v=193 öffnen.
6. Auf Android UND Windows Ladeverhalten, Arbeit, Backup und Monatswerte testen.

ACHTUNG: Lokale Browserdaten/App nicht löschen. Import ersetzt lokal vorhandene Daten.
Keine automatische Google-Drive-Synchronisierung.
